# Use shared topics in the target library graph

The target learning library uses shared topics as graph nodes, with supporting
sources accessible from each topic. Making each saved source the primary node
would split one subject across repeated article, PDF, and video nodes; shared
topics let learners explore the subject and its relationships across sources.
Automatic organization supports learner corrections and overlapping broad
areas such as AI and Math.

The graph grows from collected material rather than a preloaded subject outline:
the learner wants to see how their sources relate, so topic titles are compared
as sources arrive. Topic cards appear immediately; a connected graph appears
once at least two saved sources support a meaningful connection through a
shared substantive topic or an explainable relationship.

Shared topics are the primary graph nodes. For same-topic sources, `Combine`
shows the combined topic overview and `Keep separate` reveals individual
source-note branches under the same parent topic. Source branches preserve
individual perspectives and references while retaining one shared topic; both
views preserve the original notes.
